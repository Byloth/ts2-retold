# ADR 0005 — License: Apache-2.0

Status: Accepted (2026-11-20)

The project's own code is licensed under Apache-2.0 only (explicit patent
grant, attribution and change notices required). The license covers only what
is in this repository; it grants nothing over the original game, which users
must own.

Dependencies must be compatible with Apache-2.0 distribution; see
`docs/LICENSES.md`.
