# ADR 0007 — Recompiler codename: `andy`

Status: Accepted (2026-11-20)

The recompiler and everything that is code around it is called `andy`: binary
`andy`, crates `andy-*`, prefix `andy_` in generated code. The project and
repository remain `ts2-retold`.

The name is the one written under the toy's boot, its owner: a common first
name, not a trademark, and a fit for a tool that only works on a copy the user
owns. The protagonist's own name was rejected because it is a registered
character name (`CLAUDE.md`, rule 3).

The environment variable for the game directory stays `TS2_GAME_DIR`.
