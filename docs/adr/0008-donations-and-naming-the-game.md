# ADR 0008 — Donations are allowed; the game is named plainly

Status: Accepted (2026-11-20). Amends rules 2 and 3 of the brief.

## Decision

1. **Donations.** The project is never monetized: no ads, no paid tiers,
   nothing sold. Voluntary donations for the developer's work are allowed on
   one condition: a donation never grants anything. No access, no builds, no
   features, no early releases, no perks, no donor-only channels. Everything
   stays equally available to everyone.
2. **Naming the game.** The README, the repository description and the
   documentation say plainly that this is a recompilation of Toy Story 2 (PC,
   1999). The rights holders' names stay out of the project name, domain, logo
   and branding, and every such statement sits next to the notice that the
   project is unofficial and requires the user's own copy.

3. **Display title.** The README is headed "Toy Story 2: Retold". The
   repository name, package names, code identifiers, domain and logo stay free
   of the rights holders' names, and their logos and artwork are never used.
   The README ends with a trademark and copyright notice.
4. **Donation channel.** GitHub Sponsors, through `.github/FUNDING.yml`, as in
   the owner's other repositories.

## Why

- A donation pays for work on original open-source code, not for the game.
- Describing the project as "a 1999 platformer" helped nobody find or
  understand it; naming the game a tool is compatible with is a factual
  statement.

## Accepted risk

These choices make the project more visible to the rights holders. Using the
game's title in the project's own display title goes beyond a compatibility
statement and is the most exposed of them. Rights
holders have treated donation links on fan projects as commercial activity
regardless of how they were worded. The owner accepts this. If a takedown
request ever arrives, the display title and the donation link are the first
things to change.
