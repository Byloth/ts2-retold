# ADR 0002 — Project name: `ts2-retold`

Status: Accepted (2026-11-20)

## Decision

The repository, directory and code identifiers use `ts2-retold`. It replaces the
neutral codename `ts2-port` from the brief and satisfies the rule that the
project name must not contain the rights holders' trademarks.

The public-facing display title is "Toy Story 2: Retold" (ADR 0008).
